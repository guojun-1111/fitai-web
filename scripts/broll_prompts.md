## 生成小技巧

- **一次生成 2-3 条**，选表情最自然、构图最干净的那条下载（可灵同一条提示词每次结果不同）。
- **脸部别特写**：中景/半身最好，避免 AI 脸部崩坏。
- **光线写实最重要**：逆光/侧光比平光有质感。
- 若生成结果人物动作僵硬，把「动作」那段再写具体一点（比如「低头看手机 → 抬头望向窗外」）。

## 说明

- 脚本 `make_scenes.py` 会把圆球讲解器 + 旁白字幕烘焙到 `clip_morning.mp4`、`clip_gym.mp4` 上，输出到 `broll/`。
- 缺任一段都不报错：`splice_broll.py` 自动回退用 app 界面 + 圆球讲解器。
- 2 段齐了，`splice_broll.py` 会在这两处插真人镜头，其余走真实 app 界面，整条是「新手从不知道怎么练 → 用 FitAI 学会练」的故事。

## 完整流水线（产出 demo_v9.mp4）

```bash
python scripts/make_scenes.py        # 1. 把圆球讲解器烘焙到可灵片段
python scripts/gen_narration.py      # 2. MiniMax 合成口播 + timing
python scripts/make_demo_video.py    # 3. Playwright 录真实 app（圆球讲解器随讲解移动）
python scripts/splice_broll.py       # 4. 拼接真人镜头 + app 界面
python scripts/add_bgm.py            # 5. 混口播 + BGM → demo_v9.mp4
```
