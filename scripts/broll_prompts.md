# Demo 视频 v3 — 可灵 AI 片段生成清单

用可灵（网页 klingai.kuaishou.com 或 App）文生视频，生成下面 3 段，下载到 `data/demo_video/broll/`，文件名按第一列命名。

> **关键**：`clip_squat` 是喂给 MediaPipe 做实时骨架识别的「假摄像头」输入，**必须侧视、全身、动作慢而标准、背景干净**，否则识别不准。可灵生成的如果不够清晰，退回用手机实拍一段侧视深蹲（10 秒即可）。

## 片段清单

| 文件名 | 建议时长 | 用途 | prompt（复制到可灵文生视频，1080p） |
|---|---|---|---|
| `clip_intro.mp4` | 5s | 开场钩子 | 未来感健身场景：暗色背景，一名运动员做深蹲，周围漂浮着发光健康数据点和因果连接线，数据流环绕身体，镜头缓慢向前推进，赛博朋克蓝紫色调，电影质感，4K |
| `clip_squat.mp4` | 8-10s | 动作纠正假摄像头输入（MediaPipe 骨架识别） | 一名健身者侧面视角做标准深蹲，全身完整入镜，动作缓慢流畅，纯色简洁背景，光线均匀明亮，固定机位不晃动，真人写实风格 |
| `clip_robot.mp4` | 6s | 陪伴机器人可视化 | 一个桌面小型陪伴机器人（带小屏幕和摄像头，圆润可爱造型）正看着旁边做深蹲的人，机器人屏幕上显示实时人体骨架和计数数字，现代家庭健身场景，柔和灯光，产品级渲染 |

## 下载后放哪

```
data/demo_video/broll/
├── clip_intro.mp4
├── clip_squat.mp4
└── clip_robot.mp4
```

## 我这边会自动做的事

1. `clip_squat.mp4` → ffmpeg 转 `clip_squat.y4m`（Playwright 假摄像头要求 y4m 格式）
2. `clip_intro.mp4` / `clip_robot.mp4` → splice 步骤拼进视频对应位置
3. 用完清理中间文件，最终只留 `demo_v3.mp4`
