# FitAI 桌面健康机器人 — 硬件原理图参考

## 概述

本文档描述路线 B（核心板 + 自研底板）的详细元件选型和引脚连接。可直接用于立创 EDA 画原理图。

## 1. 核心板选择

**推荐：全志 T113-S3 核心板**（如 Yuzuki-Lizard 或 Widora T113-S3）

| 信号 | 核心板引脚 | 底板连接 |
|------|-----------|---------|
| UART2 TX | PE2 | → ESP32-S3 UART0 RX (GPIO16) |
| UART2 RX | PE3 | → ESP32-S3 UART0 TX (GPIO17) |
| I2C0 SDA | PE12 | → VL53L0X SDA + HX711 可选 |
| I2C0 SCL | PE13 | → VL53L0X SCL + HX711 可选 |
| SPI1 MOSI | PD2 | → LCD MOSI (SDI) |
| SPI1 MISO | PD3 | → LCD MISO (SDO) |
| SPI1 CLK  | PD4 | → LCD SCLK |
| SPI1 CS0  | PD5 | → LCD CS |
| LCD DC    | PD6 | → LCD DC (数据/命令) |
| LCD RST   | PD7 | → LCD RESET |
| LCD BL    | PD8 | → LCD 背光（PWM） |
| MIPI CSI  | 专用 FPC | → 摄像头模组 FPC 排线 |
| USB0 DP/DM | 专用 | → Type-C 母座（仅供电） |
| SDIO       | 专用 | → WiFi 模组（如 RTL8723DS） |
| I2S DOUT   | PG11 | → MAX98357 DIN |
| I2S BCLK   | PG12 | → MAX98357 BCLK |
| I2S LRCK   | PG13 | → MAX98357 LRCLK |

## 2. 电源管理

### 2.1 充电电路

```
Type-C VBUS (5V)
    │
    ├── TVS 管 ESD0524P (ESD 保护)
    │
    ├── IP2326 充电管理 IC
    │     ├── BAT → 18650 锂电池正极（通过 0.5Ω 检流电阻）
    │     ├── TS  → NTC 热敏电阻（10kΩ @ 25°C，电池温度保护）
    │     ├── STAT → LED 充电指示灯
    │     └── VIN → 5V
    │
    └── 18650 锂电池
          ├── 正极 → IP2326 BAT
          ├── 负极 → GND
          └── 中间抽头 → IP2326 NTC
```

**IP2326 特性**：
- 最大充电电流 3A（通过电阻可调，推荐设 1A）
- 支持 Type-C 输入
- 带电池过充/过放/过温保护
- 内置升压（电池 → 5V 输出），不需要额外的升压 IC

### 2.2 稳压电路

```
电池电压 (3.7V-4.2V) → IP2326 升压 → 5V
    │
    ├── 5V → 舵机供电（直接）
    ├── 5V → 核心板 5V 输入
    │
    ├── 5V → AMS1117-3.3 → 3.3V
    │     └── ESP32-S3 模组
    │     └── VL53L0X
    │     └── HX711
    │     └── WS2812 LED
    │     └── HC-SR501 红外
    │
    └── 5V → ME6211C33 (低噪声 LDO) → 3.3V_ANA
          └── 称重传感器模拟部分
```

**电容配置**：
| 位置 | 电容 |
|------|------|
| 5V 输入   | 100μF 电解 + 0.1μF MLCC |
| AMS1117 输入 | 10μF 钽电容 |
| AMS1117 输出 | 22μF 钽电容 + 0.1μF MLCC |
| 电池端    | 100μF 电解 |

### 2.3 电池电压检测

```
BAT+ ─── R1(100kΩ) ───┬─── R2(100kΩ) ─── GND
                       │
                    ADC 检测点 → ESP32 ADC1_CH0 (GPIO9)

Vbat = VADC × (R1+R2)/R2 = VADC × 2
```

## 3. 外设接线

### 3.1 ESP32-S3 模组（WROOM-1）

| ESP32 引脚 | 连接目标 | 说明 |
|-----------|---------|------|
| GPIO4  | HC-SR501 OUT | 红外人体传感器 |
| GPIO21 | VL53L0X SDA | I2C 数据（共用总线） |
| GPIO22 | VL53L0X SCL | I2C 时钟（共用总线） |
| GPIO7  | HX711 DOUT | 称重传感器数据 |
| GPIO8  | HX711 SCK  | 称重传感器时钟 |
| GPIO9  | 电池分压点 | ADC 电压检测 |
| GPIO10 | 舵机1 信号 | 头部舵机 PWM |
| GPIO11 | 舵机2 信号 | 手臂舵机 PWM |
| GPIO12 | WS2812 DIN | LED 灯带数据 |
| GPIO13 | 蜂鸣器 | 通过 NPN 三极管驱动 |
| GPIO16 | 核心板 PE3 (RX) | UART RX |
| GPIO17 | 核心板 PE2 (TX) | UART TX |
| EN     | 10kΩ 上拉到 3.3V + 0.1μF 到 GND | 使能引脚 |
| IO0    | 按键到 GND（烧录用） | 下载模式 |

### 3.2 VL53L0X 激光测距

```
VL53L0X 模块（I2C）
  VIN → 3.3V
  GND → GND
  SDA → ESP32 GPIO21（或共用 I2C 总线）
  SCL → ESP32 GPIO22
  XSHUT → 10kΩ 上拉到 3.3V（不休眠）
```

**说明**：VL53L0X 比 HC-SR04 超声波精度高得多（±3mm vs ±3cm），且体积小、功耗低，价格也差不多（¥8-12）。推荐优先使用。如果要用超声波做备选：

```
HC-SR04 超声波模块（备选）
  VCC → 5V
  GND → GND
  TRIG → ESP32 GPIO5
  ECHO → ESP32 GPIO6（通过 1kΩ/2kΩ 分压到 3.3V！ESP32 引脚不耐 5V）
```

### 3.3 HX711 称重传感器

```
HX711 模块
  VCC → 3.3V
  GND → GND
  DT  → ESP32 GPIO7
  SCK → ESP32 GPIO8
  E+  → 称重传感器 激励+
  E-  → 称重传感器 激励-
  A+  → 称重传感器 信号+
  A-  → 称重传感器 信号-

称重传感器（悬臂梁 5kg 规格）
  红 → E+
  黑 → E-
  绿 → A+
  白 → A-
```

### 3.4 SG90 舵机 × 2

```
舵机1（头部点头）
  棕 → GND
  红 → 5V（IP2326 升压输出）
  橙 → ESP32 GPIO10（PWM 信号）

舵机2（手臂/身体倾角）
  棕 → GND
  红 → 5V
  橙 → ESP32 GPIO11（PWM 信号）

注意：舵机堵转电流可达 750mA，两个同时动需要 5V 能供 1.5A。
     在 5V 线上加 470μF 电解电容吸收浪涌。
```

### 3.5 WS2812 LED 灯带

```
WS2812 灯带（16 颗）
  VCC → 5V（注意：16 颗全亮功耗约 16×60mA=960mA！确保 5V 供电足够）
  GND → GND
  DIN → ESP32 GPIO12（串 330Ω 电阻，防浪涌烧 IO）
  首颗 LED 的 VCC 和 GND 之间并 100μF 电解电容
```

### 3.6 MAX98357 音频功放 + 喇叭

```
MAX98357 I2S DAC 模块
  VIN → 5V
  GND → GND
  DIN → 核心板 I2S DOUT (PG11)
  BCLK → 核心板 I2S BCLK (PG12)
  LRCLK → 核心板 I2S LRCK (PG13)
  SD   → 核心板 GPIO（可选，静音控制）
  OUT+ → 喇叭 +
  OUT- → 喇叭 -

喇叭：3W 4Ω 全频喇叭（¥3-5）
```

### 3.7 蜂鸣器

```
有源蜂鸣器 / 无源蜂鸣器
  正极 → 5V
  负极 → NPN 三极管集电极（如 S8050）
  三极管基极 → 1kΩ 电阻 → ESP32 GPIO13
  三极管发射极 → GND
  蜂鸣器正负极之间并 1N4148 续流二极管（防反电动势）
```

### 3.8 HC-SR501 红外人体传感器

```
HC-SR501
  VCC → 5V
  GND → GND
  OUT → ESP32 GPIO4
  模块上两个电位器：
    - 延时调节：逆时针拧到最小（~2.5秒）
    - 灵敏度调节：中间位置（~7米）
```

### 3.9 2.4" SPI LCD 屏幕

```
2.4" TFT LCD (ILI9341 驱动，320×240)
  VCC → 3.3V
  GND → GND
  CS   → 核心板 SPI1 CS0 (PD5)
  DC   → 核心板 PD6
  RESET → 核心板 PD7
  SDA  → 核心板 SPI1 MOSI (PD2)
  SCL  → 核心板 SPI1 CLK (PD4)
  LED  → 核心板 PD8（PWM 背光控制）
```

## 4. PCB Layout 注意事项

### 4.1 基本原则
- **双层板**即可满足要求（顶层走信号 + 元件面，底层完整铺地）
- 板厚 1.6mm，铜厚 1oz
- 尺寸建议 80×60mm 以内（适配桌面机器人体积）

### 4.2 关键走线
| 信号 | 要求 |
|------|------|
| 5V 主电源 | 线宽 ≥ 1.5mm（2A 载流） |
| 舵机 5V | 线宽 ≥ 1.0mm |
| 3.3V | 线宽 ≥ 0.5mm |
| USB 差分对 (D+/D-) | 等长 ±2mm，90Ω 差分阻抗 |
| I2S | 等长 ±5mm |
| I2C | 上拉电阻靠近器件放置 |
| ADC 检测 | 远离数字信号，短路径，加 RC 低通滤波 (R=1kΩ, C=0.1μF) |

### 4.3 板边连接器
- **舵机**：2.54mm 排针（3pin × 2）
- **传感器**：2.54mm 排针（4pin 用于 I2C 总线）
- **喇叭**：2P 接线端子或 XH2.54 插座
- **电池**：XH2.54 插座
- **Type-C**：16pin 母座（仅用 VBUS + GND）
- **核心板**：邮票孔焊盘（60pin 左右，具体看核心板型号）
