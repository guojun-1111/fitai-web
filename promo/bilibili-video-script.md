# B站「个人故事流」视频脚本 + 分镜

> 定位：B站技术区 / 分享创造向，第一人称叙事「我 3 个月肝了个 AI 健身教练」。
> 时长约 2 分钟。口播可自己配音（更有个人故事感），也可用 MiniMax 合成（沿用 demo_v14 的 gen_narration.py 流程）。

## 核心钩子

**一句话**：我花了 3 个月，给自己造了个 AI 健身教练——摄像头实时纠正动作，因果推断解释恢复。

## 口播文案（分段，带时间轴）

**0:00–0:03 钩子**
> 我花了 3 个月，给自己造了个 AI 健身教练。

**0:03–0:15 动机**
> 一个人健身，最怕两件事。第一，动作错了没人告诉你——深蹲膝盖内扣、俯卧撑塌腰，练完才知道。第二，不知道什么时候该休息，怕练过头受伤，又怕练少了没效果。

**0:15–0:45 技术亮点① 实时动作纠正**
> 所以第一件事，我让它能实时纠正动作。摄像头对着你，MediaPipe 在浏览器本地做姿态估计，实时画骨架、算关节角度。膝盖内扣、下蹲不够深、身体塌陷——立刻提示。视频不出本机，隐私这块我特意做成了本地跑。

**0:45–1:15 技术亮点② 因果分析**
> 第二件事更有意思。别的 App 只能告诉你「昨天睡了 6 小时」，我让它用因果发现，从你的数据里学出「睡眠不足 → 心率升高 → 恢复下降」这样的因果链，再用贝叶斯评分告诉你今天该练还是该休。它解释的是「为什么」，不是「发生了什么」。

**1:15–1:45 demo**
> 最后我还接了个对话 AI 教练，挂了 22 个工具。可以直接问「这周练得怎么样」「明天练什么」，它是真的去查你的数据再回答，不是背话术。

**1:45–2:00 CTA**
> 整个项目开源的，核心算法全是纯 Python，没有一行 numpy。链接在简介和评论区，觉得有意思的话，给个 star。

## 制作建议

1. **口播优先自己配音**：个人故事流的灵魂是「我」的真实感，AI 配音会削弱共鸣。若时间紧，用 MiniMax 也能先出片（gen_narration.py 已有短句+慢语速参数）。
2. **前 3 秒是生死线**：镜号 1 的字幕必须 3 秒内出现，B站完播率前 3 秒流失最大。
3. **镜号 4 骨架 overlay 是本片的「wow」**，给它多留点时长，别切太快。
4. **BGM**：空灵、低音量（沿用 add_bgm.py 的空灵配乐风格），口播音量压过 BGM。
5. **导流**：B站简介能放 GitHub 链接；再在置顶评论补一条「在线体验 fitmate.top + GitHub 链接」。标题和封面别出现敏感信息。
